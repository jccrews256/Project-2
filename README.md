# Project-2: Exploring NFL Play-by-Play Data
This repository contains the code and data needed to construct an app that allows users to explore NFL play-by-play data from the 2018-2019 season. 

"Static Analysis.qmd" documents what the app can accomplish at a high level, while the "nfl_plays" folder contains specific files needed to create the app. 

Note that the main dataset the app is built from is too large for GitHub. To overcome this issue, I have created two subset csv files that exist in the repository and include all the data needed to run the app and other major analysis scripts. I have documented the data subsetting in "data_subsetting.R".
